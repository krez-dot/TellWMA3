# Tell

Tells you when you stop actually studying. Open a PDF or DOCX inside the app, take notes
beside it, and Tell watches *how* you study (restless scrolling, going idle, leaving the app).
It flags the moments you drift and shows which pages you struggled with most.

One Ionic codebase → website **and** Android app (Cordova).

## Project structure

```
web/                  ← the core Ionic app (the one shared codebase)
  index.html          all screens: Study / History / Settings tabs (Ionic components)
  css/theme.css       Tell palette mapped onto Ionic color variables, dark mode
  css/app.css         layout + responsive rules (portrait, landscape, desktop)
  js/app.js           entry point, tab bar placement, Android back button, service worker
  js/study.js         study session + restlessness detection rules
  js/viewer.js        PDF (pdf.js) and DOCX (mammoth) rendering, current-page tracking
  js/history.js       History tab: list, search, filters, detail modal, CSV export
  js/settings.js      Settings tab: every control bound with ionInput / ionChange
  js/storage.js       all localStorage reads/writes (settings, history, active session)
  js/sound.js         alert tones via Web Audio
  js/ui.js            shared helpers: formatting, ion-toast, ion-alert
  lib/                generated by the build: Ionic, pdf.js, mammoth, icons, fonts
scripts/build.js      the build step (web/ → dist/ → android/www)
dist/                 built website (deploy this, e.g. GitHub Pages)
android/              Cordova project (config.xml, icons); www/ is filled by the build
```

## Commands

```bash
npm install                # once
npm run dev                # run the web app from web/ at http://localhost:8100
npm run serve              # build to dist/ and serve it at http://localhost:8100
npm run build              # build the website into dist/
npm run build:android      # build website → copy into android/www → build the APK
```

The APK ends up at `android/platforms/android/app/build/outputs/apk/debug/app-debug.apk`.

### Android build requirements
- JDK 17, Android SDK with **Platform 36** and Build-Tools 36
- **Gradle** on your PATH (Cordova uses it to create its Gradle wrapper). On this machine:
  `export PATH="$HOME/.gradle/wrapper/dists/gradle-9.3.1-bin/23ovyewtku6u96viwx3xl3oks/gradle-9.3.1/bin:$PATH"`

## Web vs Android differences
The same files run on both. The only platform checks (`isCordova()` in `js/ui.js`):
- **CSV export**: downloads a file on the web, but Android's WebView can't download files, so it copies the CSV to the clipboard instead.
- **Service worker** (offline support / installable PWA) is registered on the web only.
- **Back button**: Android's hardware back button switches tabs or offers to end the session.
